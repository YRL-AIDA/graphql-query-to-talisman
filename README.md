# graphql-query-to-talisman

A script for sending and processing JSON messages to the Talisman framework.

## Version

1.0

## Installation

First, you need to clone the project into your directory:

```
git clone https://github.com/YRL-AIDA/graphql-query-to-talisman.git
```

Next, you need to install all requirements for this project:

```
pip install -r requirements.txt
```

*We recommend you to use Python 3.8 or more.*

## Usage

In order to use <b>graphql-query-to-talisman</b> in *console mode*, you may run the following command:

```
python main.py
```
